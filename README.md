# matchPoint

Necesito una aplicación para un smart watch

considera una pantalla cuadrada de 320x320px

Divide la pantalla en 4 cuadrantes de 160 x 160 px

Los 2 cuadrantes superiores deben estar unidos (320 X 160 px)

Los 2 cuadrantes inferiores son independientes

En el rectangulo superior existiran 2 filas y 9 columnas distribudas simétricamente

La fila[0], columnas[0 y 1] serán el nombre del jugador "local"

La fila[1], columnas[0 y 1] serán el nombre del jugador "visitante"

La fila[0,2] será el marcador del primer set, del jugador local, al estar activo será de color azul eléctrico, cuando finalice el set pasará a color azul marino

La fila[1,2] será el marcador del primer set, del jugador visitante, al estar activo será de color azul eléctrico, cuando finalice el set pasará a color azul marino

El cuadrante inferior izquierdo, será el marcador del jugador local

El cuadrante inferior derecho, será el marcador del jugador visitante

El cuadrante inferior izquierdo debe tener margen superior 2 px y derecho 1 px

El cuadrante inferior derecho debe tener margen superior 2 px e izquierdo 1 px

Te dejo una imagen de referencia para que puedas entender de mejor forma el requerimiento

Puedes proponer una paleta de colores que sea amigable y legible
